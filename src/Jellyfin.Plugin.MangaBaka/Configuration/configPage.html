Local database

MangaBaka publishes a nightly snapshot of its whole catalogue. With a local copy, matching a library needs no network requests at all — which is what makes refreshing everything at once practical. Download it from Dashboard → Scheduled Tasks → Download MangaBaka database, which then repeats weekly. The download is about 540 MB and roughly 525 MB is kept on disk under the plugin's data folder.
The local database answers exact title matches; the search API covers the rest, and is the only source until the database has been downloaded. Local database only keeps the plugin entirely offline — and matches nothing at all until you run the download task.
Off means the bulk refresh only fills gaps. On also overwrites hand-made corrections.
